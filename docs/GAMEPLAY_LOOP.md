# Gameplay Loop

1. Player moves around the production area.
2. A machine produces an item over time.
3. Player approaches and collects the finished item.
4. Collected items become sellable inventory.
5. Player sells items to receive money.
6. Money upgrades production speed, capacity and value.
7. New land becomes available after unlock requirements.
8. Newly unlocked land provides room for additional machines.

The first playable build should prioritize a short, understandable loop over visual complexity.
