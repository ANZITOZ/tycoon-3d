# Tycoon 3D

Mobile 3D tycoon game built with Unity.

## Core vision

A mobile 3D production-and-expansion tycoon inspired by the satisfying progression loop of farming/management games, but with its own world, machines, resources, economy and visual identity.

The player starts with a small production area and gradually builds an industrial operation.

## Gameplay loop

1. Produce resources.
2. Collect products.
3. Sell products for money.
4. Upgrade machines.
5. Unlock new land.
6. Build new machines.
7. Create production chains using inputs and outputs.
8. Unlock new machines and resources through player progression.
9. Expand the operation and increase production value.

## Planned machine progression

### Level 1 — Basic production
- Basic Producer
- Output: Basic Product
- Simple sell loop

### Level 2 — Processing
- Processor
- Input: Basic Product
- Output: Processed Product
- Higher selling value

### Level 3 — Advanced production
- Refinery / Advanced Machine
- Input: Processed Product + secondary resource
- Output: Advanced Product
- Higher production value

### Level 4+ — Expansion
- Multiple machine types
- Specialized production chains
- Larger land plots
- Faster machines
- Storage upgrades
- Decorative and functional buildings
- New resource areas
