# Tycoon 3D

Mobile 3D tycoon game built with Unity.

## MVP
- 3D player controller
- Mobile joystick
- Isometric camera
- Production machine
- Item production and collection
- Selling
- Money/economy
- Machine upgrades
- Land unlocking

## Project structure
See docs/PROJECT_STRUCTURE.md.

## Development
The repository is being built incrementally. Systems are modular so the prototype can evolve into a complete mobile game.
